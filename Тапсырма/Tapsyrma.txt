1. ЖАҒДАЯТ
------------------------------------------------------------------------------
Сіз «Қазан» дәмханасына кіші веб-әзірлеуші (junior developer) болып жұмысқа
орналастыңыз. Дәмхананың сайты арқылы клиенттер мәзірді қарап, тағамды
себетке салып, үйге тапсырыс береді және тапсырыстың күйін бақылайды.

Алдыңғы әзірлеуші жұмыстан кетер алдында сайтты асығыс жаңартып кеткен.
Содан бері клиенттер мен менеджерлерден шағым көп түсіп жатыр. Тимлид сізге
шағымдардың тізімін берді (4-бөлім) және былай деді:

    «Сайт жоба ретінде дұрыс құрылған, оны қайта жазудың қажеті жоқ.
     Қателер әр жерде — Python кодында да, шаблондарда да, стильде де,
     JavaScript-те де, дерекқорда да бар. Әр қатені тауып, ЕҢ АЗ өзгеріспен
     түзет, не істегеніңді есеп етіп жаз.»

3. ЖОБАНЫ ІСКЕ ҚОСУ
------------------------------------------------------------------------------
Қажет: Python 3.9 немесе жаңарақ нұсқасы. Тексеру:  python --version
Flask кітапханасын орнату үшін бір рет интернет қажет.

Windows
  1-тәсіл (оңай): 1_Qatesi_bar папкасындағы iske_qosu.bat файлын екі рет
  басыңыз.

  2-тәсіл (терминал):
      cd 1_Qatesi_bar
      python -m pip install -r requirements.txt
      python app.py

Linux / macOS
      cd 1_Qatesi_bar
      python3 -m venv venv
      source venv/bin/activate
      pip install -r requirements.txt
      python3 app.py

Терминалда «Running on http://127.0.0.1:5000» жазуы шыққанда, браузерде
мына мекенжайды ашыңыз:

      http://127.0.0.1:5000

Серверді тоқтату: терминалда Ctrl + C.

Сервер debug режимінде жұмыс істейді: Python файлын сақтағанда ол өзі қайта
іске қосылады. CSS және JS файлдарын өзгерткеннен кейін браузерде бетті
Ctrl + F5 арқылы жаңартыңыз (кэшті елемей жүктеу).

Дерекқор (instance/qazan.sqlite) бірінші іске қосқанда schema.sql файлы
бойынша өзі құрылады. Дерекқорды қайта құру үшін серверді тоқтатып, мына
екі тәсілдің бірін қолданыңыз:
  - instance/qazan.sqlite файлын өшіру (келесі іске қосқанда қайта құрылады);
  - терминалда:  python -m flask --app app init-db

------------------------------------------------------------------------------
Шағымдар клиенттер мен менеджерлердің сөзімен жазылған. Ретпен тексерген
дұрыс: кейбір қате келесі қатені жасырып тұр.

  №1  «Мәзірден "Сусындар" санатын таңдаймын, бірақ бетте бешбармақ та,
       палау да, бәрі шыға береді. "21 тағам" деп тұр, сусын 4-ақ қой.»

  №2  «Тағам бетінде санын көбейтейін деп "+" басамын — 1-ден кейін бірден
       11 болып кетеді, тағы бассам 20. Ал "−" дұрыс жұмыс істейді.»

  №3  «"Себетке қосу" батырмасын басамын — ештеңе болмайды. Бет те
       жаңармайды, қате де шықпайды.»

  №4  «Сайт ешқандай хабарлама көрсетпейді: "себетке қосылды" да, "себет
       бос" та жоқ. Менеджер оларды кодта көрдім дейді, бірақ экранда жоқ.»

  №5  «Тағамды себетке қостым деп ойлаймын, себетке кірсем — бос.»

  №6  «Менің тапсырысым 15 000 теңге, бірақ жеткізуге 800 теңге алды.
       Ал досым 2 000 теңгеге тапсырыс берсе, оған тегін. Сайтта
       "10 000 ₸-ден бастап тегін" деп жазылған ғой?»

  №7  «"Тапсырысты растау" батырмасын басқаннан кейін қате беті шығады.
       Бірақ менеджер тапсырыс келді дейді. "Тапсырыс күйі" бетінен
       тапсырысты ашсам да — тағы қате.»

  №8  «Кеше тапсырыс бердім, бәрі жақсы болды. Бүгін сол телефон нөмірімен

5. ҚАТЕНІ ҚАЛАЙ ІЗДЕУГЕ БОЛАДЫ
------------------------------------------------------------------------------
Сервер терминалы
  Әр сұраныс терминалда көрінеді:  "POST /cart/add HTTP/1.1" 302 -
  500 қатесі болса, терминалда және браузерде толық traceback шығады.
  Traceback-ті төменнен жоғары қарай оқыңыз: ең соңғы жол — қатенің түрі,
  оның үстінде — қате болған файл мен жол нөмірі.

Браузердің әзірлеуші құралдары (F12)
  Elements  — HTML-ді және элементке қолданылған CSS ережелерін көру.
              Оң жақтағы Styles / Computed бөлімінде элементтің нақты
              стилі (мысалы, opacity, display) көрінеді.
  Console   — JavaScript қателері, сондай-ақ кез келген өрнекті тексеру:
              мысалы,  "1" + 1   және   "1" - 1   нәтижесін салыстырыңыз.
  Network   — батырманы басқанда серверге сұраныс кетті ме, жоқ па,
              қандай жауап келді (200, 302, 404, 500).
  Application → Cookies — Flask сессиясы осы жерде сақталады.

Код
  Маршруттар:            qazan/catalog.py, qazan/cart.py, qazan/orders.py
  Есептеу:               qazan/pricing.py
  Шаблон сүзгілері:      qazan/filters.py
  Дерекқор құрылымы:     qazan/schema.sql
  Шаблондар:             qazan/templates/
  Стиль және скрипт:     qazan/static/css/style.css, qazan/static/js/main.js

Дерекқор
  SQLite файлын DB Browser for SQLite бағдарламасымен немесе VS Code-тағы
  SQLite кеңейтуімен ашып, кестелерді қарауға болады.
